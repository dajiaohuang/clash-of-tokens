## 证据与后续验收

具体源码固定版本和请求说明见 [腾讯 ima](providers/tencent-ima.md)、[微信读书](providers/weread-ai.md)。本地测试验证协议转换，不能证明当前 App 账号可用。

纳米公开 bundle 的 SHA-256 为 `cc213e91ed463727b2bc4b3f79b2d160d0a0bbeb2f37f4870ab8ff0061531fe2`；其中会动态取得 Chat-Token，不能把公开 JS 中看到的路径当成无需签名的通用 API。知乎本次未登录；夸克公开入口本次返回品牌主页。详情证据 URL 保存在 JSON。

“缺少协议”是本次研究和本机条件的限制，不表示世界上不存在实现。搜索命中同名项目、功能宣传、开放平台消息 API 或反向接入外部 LLM 都不足以验收 App 自身为 provider。

每个阻塞项下一步需要对应 App/网页版的可访问会话，以及去除凭证的请求与响应样本（包含成功终止、错误和取消情况），或可核验的协议源码。之后实现账号隔离、能力拒绝、终止检测与测试，再用自己的账号 smoke test。不要将 token、Cookie、HAR 或设备私密数据提交到仓库。
