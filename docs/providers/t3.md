# T3.chat

This experimental adapter ports the executable `/api/chat` request in
[the pinned OmniRoute reference](https://github.com/OmniRoute/OmniRoute/blob/ba597b631d22d85e56db6982f24b7d1ebe238df9/open-sse/executors/t3-chat-web.ts).
The reference's introduction claims dynamic TanStack server-function discovery,
but its implementation does not perform it. Neither does this port. Compatibility
with the current hosted product has not been verified. Framed TSS fails explicitly.

Set the source credential environment variable to your own full Cookie header,
including `convex-session-id`, or a JSON object containing `cookie`. No login,
cookie renewal, account provisioning, or server function hash discovery is included.
Use an exact product model ID. One user text message is accepted; sessions,
history, tools, attachments, and unsupported generation fields are rejected.

The adapter sends a streaming request and buffers the answer. It accepts JSON,
NDJSON typed text envelopes, and SSE with an explicit terminal record. A broken
or unterminated stream fails instead of producing a successful partial answer.
Upstream errors are redacted, response sizes are bounded, and redirects are disabled.

Local HTTP fixtures check the request path, cookie and payload, typed text
decoding, immediate close at the end marker, malformed records and truncation.
These fixtures establish migration behavior, not production availability.
