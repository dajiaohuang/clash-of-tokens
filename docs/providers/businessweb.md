# Business and workspace web sources

`internal/providers/businessweb` contains five opt in native adapters whose
request and response contracts are present in the pinned source inventory:

| Inventory | Adapter | Upstream surface | Authentication |
| ---: | --- | --- | --- |
| 81 | `gemini-business` | Gemini Business `StreamGenerate` | Existing enterprise cookies |
| 82 | `aistudio-build` | Native Gemini fetch inside an operator-owned AI Studio Build preview | Configured authenticated Chrome |
| 83 | `aistudio-playground` | MakerSuite `GenerateContent` JSON+protobuf RPC | Existing browser cookie and headers |
| 87 | `copilot-m365` | Microsoft 365 Copilot SignalR WebSocket | Existing access token and `user@tenant` path |
| 91 | `promptql` | PromptQL Hasura GraphQL thread API | Existing bearer token and project id |

All five adapters expose text-only OpenAI Chat Completions through the
provider client. The client accepts one bounded JSON request, rejects unknown
fields, requires a final user turn, and returns either a buffered completion or
a buffered SSE response. It does not create accounts, refresh anonymous
quotas, rotate guest sessions, import browser profiles, or forward caller
authentication headers. `X-COT-Session` is rejected because these adapters
start an independent upstream turn. PromptQL continuation is rejected until model and thread binding can be verified.

AI Studio Build uses `browser.cdp_url` and an operator-owned `https://ai.studio/apps/<app-id>` base URL. Other credentials are supplied through each source's `key_env` variable. Values may
be a single token/cookie or a JSON object. Representative shapes are:

```json
{"cookie":"__Secure-1PSID=...; __Secure-1PSIDTS=...; SAPISID=..."}
```

```json
{"access_token":"..."}
```

```json
{"cookie":"SAPISID=...","x_goog_api_key":"...","visit_id":"...","proof":"..."}
```

```json
{"access_token":"...","chathub_path":"<user-oid>@<tenant-id>"}
```

```json
{"token":"...","project_id":"<project-id>","llm_config_id":"<your-model-config-uuid>"}
```

Gemini Business derives the documented `SAPISIDHASH` when the cookie contains
`SAPISID` and parses length-prefixed `wrb.fr` snapshots. AI Studio Playground
uses the sparse MakerSuite array shape and can send a captured WAA `proof`;
the proof is not generated by this gateway. AI Studio Build uses the configured app preview frame for native Gemini fetch calls; it has no author app URL default. PromptQL starts a new
thread and polls `thread_events` until a final response event. Copilot sends
the SignalR handshake, chat invocation, and Metrics frame in the documented
sequence, echoes keepalive frames, and honors the caller context while waiting
for completion.

`base_url` may be a loopback HTTP fixture for local testing; configured public
endpoints must use HTTPS. The M365 WebSocket similarly requires WSS outside a
loopback test endpoint. Upstream response bodies and errors are bounded and
are not copied into gateway errors. These adapters have local protocol-fixture
coverage only; `live_verified` remains false until a real, user-authorized
account is exercised.

## Source evidence

The implementation is based on the pinned references and keeps their wire
contracts in Go rather than importing reference runtime code:

* [OmniRoute Gemini Business executor](https://github.com/diegosouzapw/OmniRoute/blob/release/v3.8.51/open-sse/executors/gemini-business.ts)
* [iBUHub AIStudioToAPI](https://github.com/iBUHub/AIStudioToAPI)
* [Mag1cFall AIStudio2API](https://github.com/Mag1cFall/AIStudio2API)
* [OmniRoute Copilot M365 executor](https://github.com/diegosouzapw/OmniRoute/blob/release/v3.8.51/open-sse/executors/copilot-m365-web.ts)
* [OmniRoute PromptQL executor](https://github.com/diegosouzapw/OmniRoute/blob/release/v3.8.51/open-sse/executors/promptql.ts)


Gemini Business accepts one user message and a pinned text model. Playground preserves full text history and separates content frames from the explicit normal completion frame. M365 and PromptQL use the sole selector `web`; the actual service or operator-supplied configuration selects the model. No measured usage is invented when the source does not return token counts.
